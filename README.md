# Neopixel Clock Case
A case for my repo "neopixel clock" This case gives the fragile hardware a place to live and makes it look way better, this case includes a base designed to not slide around using feet that have a very small contact surface area with the desk, it also has raised numbers for added readability, it features a removable back design so that the acrylic can be glued in place and no bulky attachment hardware will be visible, this back also makes it very easy to repair something later on, the case also features holes in the side for both ventilation to the leds and esp32 as well as the pcb itself as all those things may get a little toasty, and it lets the light spill out the sides, which should make cool patterns on the walls, when making this project, I learned a lot about circular patterns and debossing in fusion.
