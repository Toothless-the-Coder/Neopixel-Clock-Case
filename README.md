# Neopixel Clock Case

## Overview

A case for my repo "Neopixel Clock." This case gives the fragile hardware a place to live and makes it look way better.

The case includes a base designed to not slide around, using feet that have a very small contact surface area with the desk. It also has raised numbers for added readability.

It features a removable back design so that the acrylic can be glued in place and no bulky attachment hardware will be visible. This back also makes it very easy to repair something later on.

The case also features holes in the sides for both ventilation to the LEDs and ESP32, as well as the PCB itself, as all those things may get a little too toasty. It also lets the light spill out the sides, which should make cool patterns on the walls.

## Design Features

- **Non-slip base:** The feet have a very small contact surface area with the desk to help keep the case from sliding around.
- **Raised numbers:** The raised numbers make the clock easier to read.
- **Removable back plate:** The back makes it possible to glue the acrylic in place without bulky attachment hardware being visible.
- **Easy repairs:** The removable back makes it much easier to access the hardware if something needs to be repaired later on.
- **Ventilation:** Holes in the sides help provide ventilation for the LEDs, ESP32, and PCB.
- **Side lighting:** The holes also let light spill out the sides, which should make cool patterns on the walls.

## How the Back Plate Works

The back plate is held on by gravity and physics. The little tab thing at the top and the stand on the bottom both hold it in place.

This keeps the design simple while still making the back removable for repairs.

## Challenges and What I Learned

When making this project, I learned a lot about circular patterns and debossing in Fusion.
